# TOROBYTE Lovable Skills

Skills internas para desarrollar plataformas empresariales CRM, ERP y SaaS con Lovable.

## Skills

- [`torobyte-crm-standards`](skills/torobyte-crm-standards/SKILL.md): estándares de diseño CRM, arquitectura React/TypeScript, seguridad, APIs, integridad de datos y refactorizaciones seguras.

## Uso en Lovable

Importa la carpeta `skills/torobyte-crm-standards` desde GitHub mediante Settings → Skills → Add → Import from GitHub.

Este repositorio contiene guías de desarrollo, no código ejecutable. Las modificaciones a una aplicación requieren autorización explícita.
